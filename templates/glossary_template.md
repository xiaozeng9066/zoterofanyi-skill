# 项目术语表 v2（术语＋概念释义＋禁止混用的近似词）

> 用法：翻译时以本表为准；表中「禁止混用」列列出**在本文语境下会改变含义**的近似词。
> 标注「待核实」的条目**不得擅自确定译名**，须保留原文并注明疑点。

## 一、核心研究概念

| 英文 | 中文（约定） | 概念释义 | 禁止混用 / 近似词 |
|---|---|---|---|
| peer effects | 同伴效应 | 同伴群体的行为或特征对个体结果的影响 | 同辈效应、同伴影响、朋友效应 |
| peer group | 同伴群体 | 被定义为参照对象的同龄/同校/同社区群体 | 同伴组、同辈群体 |
| peer effects on bodyweight | 同伴体重效应 | 同伴对个体体重的影响 | 勿与"同伴肥胖"混（后者指同伴自身的肥胖状态） |
| bodyweight / body weight | 体重 | 个体体重本身 | 勿与 BMI、肥胖、超重互换 |
| BMI | BMI（体质指数） | 体重(kg)/身高(m)² | 与 bodyweight 不是同一概念；勿把 BMI 译作"体重指数"以外的自造词 |
| obesity | 肥胖 | 按 IOTF/CDC 阈值判定 | 超重（overweight）——两者阈值不同，**不得互换** |
| overweight | 超重 | 高于正常但未达肥胖阈值 | 肥胖——同上 |
| waist circumference (WC) | 腰围 | 腹型肥胖的测量指标 | BMI、体脂率 |
| abdominal obesity | 腹型肥胖 | 以腰围判定 | 肥胖（全身性） |

## 二、计量经济学 / 识别框架（本文最关键，易混）

| 英文 | 中文（约定） | 概念释义 | 禁止混用 / 近似词 |
|---|---|---|---|
| correlated effects | **相关效应** | 个体与同伴受**共同的不可观测因素**影响而呈现相关 | **关联效应**（旧译，已废弃）、情境效应 |
| contextual effects (= exogenous effects) | 情境效应（外生效应） | 同伴群体的**其他特征**（非行为本身）对个体的影响 | 相关效应、同伴效应 |
| selection effects | 选择效应 | 个体**选择**与自己相似的同伴 | 相关效应 |
| reflection problem | 反射问题 | 难以区分"同伴影响我"与"我影响同伴" | 反映问题、镜像问题 |
| identification (strategy) | 识别（策略） | 用外生变异分离出因果效应 | 鉴定、辨识、辨别 |
| endogeneity | 内生性 | 解释变量与误差项相关 | 内在性 |
| instrumental variable (IV) | 工具变量 | 与内生变量相关、与误差项不相关 | 工具变数 |
| fixed effects | 固定效应 | 控制不随时间变化的不可观测异质性 | 固定效果 |
| quantile regression | 分位数回归 | 在第 τ 分位点估计条件分布 | 分位回归 |
| ordered probit | 有序 probit | 有序离散因变量的 probit 模型 | 排序 probit |
| marginal effects | 边际效应 | 自变量变动一单位对结果的影响 | 边际效果、边际影响 |
| robust standard errors | 稳健标准误 | 对异方差稳健的标准误 | 稳健标准误差；**勿与自助法标准误混** |
| bootstrapped standard errors | 自助法标准误 | 通过重抽样估计的标准误 | 稳健标准误 |
| confidence interval (CI) | 置信区间 | 95% 为本文默认 | 可信区间、信赖区间 |
| dummy variable | 虚拟变量 | 0/1 指示变量 | 哑变量（可接受但需全篇统一）、假变量 |
| z-score | z 分数 | 标准化后的取值 | 标准分（可接受但需统一）、Z 值 |
| translog | **待核实**（保留英文） | 原文既称 translog 又称"所有模型为 log-log 形式"，指对数变换或超越对数函数形式**无法仅凭原文确定** | 超越对数、超对数、对数化——**均不得单独使用**；须保留 `translog` 并加译者注 |
| log-log form | 对数—对数形式 | 被解释变量与解释变量均取对数 | 双对数（可接受但需统一） |
